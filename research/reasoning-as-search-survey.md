## 0. 五问的答案（先行）

> **Q1（AC1）：BFS/DFS 的最优性定理在 token 空间**几乎逐条失效**——而且**失效的根因不是"landscape 非凸"，是"目标函数不是搜索要找的那个东西"**。六条经典假设里，**只有"无环"在形式上成立**（前缀树是 DAG），其余五条（有限分支因子、可加边权、确定性转移、可判定的 goal test、**可采纳启发式**）全部被违反。其中最致命的是**最后一条**：A\*/best-first 的最优性要求 `h ≤ h*`（可采纳），而 LLM 的价值估计是**学出来的、没有可采纳性证明**——**用不可采纳的启发式，最优性定理直接作废**。
> **但要给出一篇例外（§3.5）**：`2609.38672` 确实把 beam search 的 test-time scaling 做成了**定理**——只是它的量词是**"最优响应存活的样本复杂度"**（vanilla beam 需 **Ω(C\*(x)²)** 个样本，C\* 是 token 级覆盖系数），**不是"beam search 找到最优"**。→ **在这个空间里能得到的定理，形状必然是"需要多少样本"，不是"保证最优"。**

> **Q2（AC2）：有定理，但两条经典定理都以"不可操作"的方式成立；真正能迁移的是三条 2024–2026 的新结果。**
> - **模拟退火（Hajek 1988）**：冷却是 `T_k = c/log(1+k)` 且 **c ≥ d\***（最深非全局局部极小的深度）时，**收敛到全局最优是"必要且充分"的**——但 d\* 不可计算，收敛是 t→∞ 的 in probability，且 `2208.11444` 已证明**即使按这个"理论上最优"的调度，解集在期望上仍远离全局最优**。→ 定理真，保证空。
> - **UCT/MCTS（Kocsis & Szepesvári 2006）**：regret `O(log n)` 的前提是**有限树 + 有界值 + 对抗性对手**（two-player zero-sum）。LLM 推理**没有对手**，价值来自同一个模型 ⇒ 借用的是框架，不是界。
> - **能迁移的三条**：① **beam search 的样本复杂度界**（`2609.38672`）：vanilla beam 要 **Ω(C\*²)** 个样本才能让**最优响应存活**，confidence-filtered beam（CF-Beam）把它降到 **Õ(C\*)**（在 prefix competitiveness + 固定 horizon/gap/精度下），并给出 regret 上界与 **Ω(√(C̄·ε_RM²))** 的下界——**这是唯一一篇既叫"provable"、又直指 beam search 的**。② **覆盖 vs 选择的分离**（`2606.28661`）：`pass@n ≤ 1-(1-s)^n` 是覆盖率保证，但样本相关 ρ>0 时有效样本数上有**天花板 `n_eff → 1/ρ`**，而自一致性（选择）**不能超过众数命中率 `π_mode`**——实测量化：GSM8K 上 10⁴ 采样，**覆盖升到 1.00，自一致性停在 0.87**。② **compute-optimal 分配**（`2408.03314`）：给定 FLOPs，最优策略随**题目难度**切换（易题串行修订、难题并行搜索+验证器），比固定 best-of-N 高效 **>4×**。

> **Q3（AC3）：有人做过，但**没有人给出"LLM 推理 = 搜索"的最优性定理**；最接近的三篇各覆盖一块，合起来是一片拼不上的地图（§4 表）。**最关键的一篇是 `1908.10090`**：它做了**精确搜索**，结果发现**精确最优的答案经常是垃圾**（51.8% 的句子最优解是空串，BLEU 从 30.3 掉到 2.1）——**这是对"更好的搜索 ⇒ 更好的输出"最干净的反例**。

> **Q5（追加，成璐 2026-11-08 转向）："通用最优是幻想，场景适配才是真的"——那么 meta-level 的动态适配能不能培养？**
> **能，但不是"学会选搜索算法"，而是"学会判何时该多想"**（§9）。四条子答案：
> **Q5.1** 有文献识别的路由信号里，**只有"错误代价不对称"有定理**（Chow 阈值 `c_fp/(c_fp+c_fn)`）；其余三个候选（答案空间大小/唯一解/可分解）只有经验关联。而且 **`2505.13379` 给出一个反例式负结果：在 AIME（连推理模型都只有 28%）上"路由器识别不出它难"** ⇒ **路由信号必须同时含"模型自身能力"，不能只看题目难度**。
> **Q5.2** 切换成本**只被量化了"总成本"，没被量化"切换本身"**：Anthropic effort 低→max 输出价差约 **5.8×**（Gemini Flash \$0.60 vs \$3.50/M）；eliminating filler 可减 **27%–51%** 长度且不掉分（NoWait）；但**"中途换策略"的代价是空白（N7）**。
> **Q5.3** **可激发，但只到"结构"不到"调度"**：Self-Discover 用纯 prompt（SELECT/ADAPT/IMPLEMENT）把结构选择做到 **+30%**、策略依从率 **32%–99%**；但**"何时想"这件事必须被训练**（Thinkless/AdapThink/SelfBudgeter 全都要 RL 或两阶段）——最硬的证据是 `2510.07364`：**零权重更新、只 steer 12% 的 token，就恢复了 base→thinking 差距的 91%**，即"thinking 模型主要学的是**何时**调用已有机制"。
> **→ 所以 Q5.3 的答案是：它撞的不是三面墙中的任何一面，而是第四面——"调度墙"**（机制已在、缺的是调用策略）。这面墙是**本报告的综合**，不是文献既有概念（conf 0.55，见 §9.3）。
> **Q5.4** 三个动作的映射**基本成立但要各加一条修正**：整理 = **剪枝 + 压缩**（不是纯剪枝，压过头会剪掉还要用的 open list：ACE 记录的 context collapse **18,282→122 tokens、66.7%→57.1%**）；写SOP = **缓存已探索路径（macro-operator + transposition table）**，经典风险是 **utility problem**；研究推进 = **迭代深化（IDA\*）**，前提是每轮有更好的 bound（=更好的 verifier）。

> **Q4（AC4）：推荐抽象是 (b)"受限前缀搜索 + 外部工作内存"，并把 (c) 作为预算层；但要加一条第一性修正——"搜索不是瓶颈，目标对齐才是"。**

## 1. 先纠正类比本身（这一步不做，后面的讨论全部跑偏）

任务书的提醒是对的，我把它做成一张对照表：

| 常见类比 | 实际是什么 | 为什么不准 |
|---|---|---|
| "LLM 默认解码 ≈ 深搜" | **greedy = beam width 1 = hill climbing** | DFS 的定义特征是**回溯**；greedy 一旦选了就不回头。把 greedy 叫 DFS，等于把"不回溯"说成"深搜" |
| "beam search ≈ 宽搜" | **beam search = 有界宽度的 best-first（内存受限版）** | BFS 按**深度层**扩展且不剪枝；beam search 每层**按分数剪枝**。经典定义明确：beam search **既不完备也不最优**（牺牲完备性以换可控内存） |
| "self-consistency = 多次搜索取最优" | **randomized restart + plurality vote** | 没有共享搜索树、没有回溯、没有启发式；它是**独立采样 + 聚合**，属于"重复试验"家族 |
| "ToT = 真正的树搜索" | **是树搜索，但启发式不可采纳** | 有分支、有剪枝、有评估，但评估由 LLM 自己给 ⇒ `h` 可能 > `h*` ⇒ 最优性定理不适用 |

**一句话**：**"LLM 在搜索"这个说法在三种完全不同的意义上被使用**——自回归的**逐 token 选择**（必然发生，且是免费的）、推理策略的**前缀分支**（需要外部干预才发生）、以及**多次独立试验**（并行且互不共享）。**只有第二种才配得上"搜索"这个词，而它恰恰是现有系统做得最少的。**

## 2. Q1：逐条违反清单（AC1）

经典搜索的最优性/完备性定理，前提可以拆成六条。逐条对照 LLM 自回归生成：

| # | 经典假设 | LLM 的实际 | 是否违反 | 后果 |
|---|---|---|---|---|
| **A1** | **有限分支因子 b**，故 BFS 复杂度 O(b^d) | b = \|V\| ≈ 10⁵；d = 10³ token ⇒ 空间 ≈ 10^(5×10³)。**且存在两个尺度**：token 分支（巨大但多数等价）与语义分支（小但不可自动枚举） | **违反（数量级）** | 穷举不可行；"完备性"只剩形式意义 |
| **A2** | **边权非负且可加**（最优子结构） | 边权 = log p(token \| prefix)，**非负**（每个 log p ≤ 0）；但**可加性一旦做长度归一化就破**。`D17-1227` 明确：length normalization 与 length reward "**invalidate the optimal property**"，只有**有界**长度奖励才能保住 Theorem 3 | **违反（可加性）** | 只要用了长度惩罚，最优性证明即失效 |
| **A3** | **无环或可检测环** | token 前缀树**天然是 DAG**（前缀唯一，不会回到同一节点）；但**语义层有环**（重复同一段推理），而 token 层看不见 | **形式上成立 / 语义上违反** | 检测"绕圈"需要语义判据，图算法给不了 |
| **A4** | **确定性转移** | temperature=0 近似确定（浮点/batch 仍有非确定性）；**temperature>0 时是随机转移** | **违反（采样解码）** | 确定性最优性定理**只在 greedy 下**有意义，而采样恰恰是 self-consistency 的前提 |
| **A5** | **goal test 可判定**（能判"到没到终点"） | LLM **没有** goal test；必须外接 verifier。而"答案对不对"通常要等生成结束才知道 | **违反** | 搜索无法自己停；所有"停止"都是外部规则 |
| **A6** | **启发式可采纳**：`h(n) ≤ h*(n)` | LLM 的价值/打分是**学出来的**，**没有任何可采纳性证明**——而且经验上会高估（overconfidence，见 T-PR-13 §2.1） | **违反（最致命）** | **A\*/best-first 的最优性定理直接作废**；这正是 ToT/RAP 借用搜索框架却拿不到界的原因 |

**最干净的反例（比任何论证都强）**

`1908.10090`（Stahlberg & Byrne, EMNLP 2019）用**精确解码**（beam + DFS，利用 log-prob 单调性剪枝）量化了 beam search 离最优有多远：

| 解码方式 | BLEU | 搜索错误率（Transformer-Base） | 空译文比例 |
|---|---|---|---|
| Exact（真·全局最优） | **2.1** | 0%（按定义） | **51.8%** |
| Beam-10 | 30.3 | **57.7%** | 远低于 51.8%（空串被搜索错误挡住） |
| Beam-100 | — | **53.62%**（宽度 ×10，只降约 4 个点） | 未在摘要中单列 |
| Greedy | — | 73.58% | 未在摘要中单列 |

**读法**：**"更优的搜索"直接把 BLEU 从 30.3 打到 2.1**，因为**模型给空串的分数最高**。原文的措辞是"search errors, paradoxically, often **prevent** the decoder from suffering from a more serious **model** error"。
→ **这证明的不是"搜索不够好"，而是"搜索的目标函数与效用不对齐"**：在错的目标上做最优搜索，结果比近似搜索更差。**这一条应当作为整个"推理即搜索"路线的第一性警告。**

**A2 的补充证据：**

`D17-1227`（Huang et al., EMNLP 2017）确实给出了 beam search 的**最优性定理**——但注意它的限定：

> **Theorem 1（optimality）**：算法终止时，当前最佳完整假设是所有完整假设中的最高分者——**"modulo beam size"**（在 beam 之内）。
> 终止条件是 **"optimality certificate"**：当前 beam 的最优项 `B_1 ≤ best_{≤i}`。
> **Theorem 3（modified optimality）**：加入**有界**长度奖励后仍成立。

**"modulo beam size" 正是问题本身**：保证的是"**在你已经保留的候选集合里的最优**"，而丢掉的候选**永远不会回来**。→ 这条定理**不提供对全局最优的任何保证**，它提供的是"**别再往前搜了**"的正确性证明（一个**终止**定理，不是一个**最优性**定理）。

## 3. Q2：非凸/随机下仍有保证的策略（AC2）

### 3.1 经典保证之一：模拟退火（Hajek 1988）——**定理真，保证空**

**定理陈述（原文口径）**：设状态空间 S 上的 Markov 链 `(S, V, N)` **不可约**且满足**弱可逆性（WR）**；温度 `{T_k}` 非增且 → 0。则
- (a) 对任何**非局部极小**的状态 x：`lim_{k→∞} P{X_k = x} = 0`；
- (b) 收敛到**全局最小集** ⟺ 冷却条件成立。
**特例**：若 `T(t) = c/log(1+t)`，则收敛 ⟺ **`c ≥ d*`**，其中 `d*` = **最深的一个非全局局部极小的深度**。

**为什么这个保证不可用（三条，逐条致命）**
1. **`d*` 不可计算**：要先知道整个 landscape，才能定 c。→ 定理是"存在一个常数"，不是"给一个常数"。
2. **收敛是 `t → ∞` 的 in probability**：对数冷却所需的迭代数是**指数级**的。
3. **`2208.11444` 直接把这条路堵了**：作者对 TSP 的随机实例分析显示，**Hajek 的"理论最优"冷却调度所探索的解集，在期望上仍远离全局最优**；他们据此提出"对数冷却在实践上应当被牺牲"，并试图给出平均情况下的运行时下界。

→ **判决：SA 的定理在 LLM 上不可操作。** 更根本的是：SA 需要**可评估的目标函数**，而 LLM 推理的目标（答案是否正确）**在搜索过程中不可评估**（A5 违反）。**把 SA 搬到 LLM 推理上，等于要求 verifier 在每一步都可用——这已经不是"搜索算法"问题了。**

### 3.2 经典保证之二：UCT/MCTS——**界依赖"有对手"，LLM 没有**

UCT（Kocsis & Szepesvári 2006）的 regret 界是 `O(log n)`，其**适用条件**是：有限深度树、**有界即时奖励**、且值由 **minimax** 定义（即存在一个**对抗性对手**在交替落子）。
- 在 LLM 推理里：没有对手，只有一个**随机的环境**（采样）和一个**有偏的价值函数**（同一模型）。
- → 借用 MCTS 的**算法骨架**（选择/扩展/回传）是可以的（RAP `2305.14992` 就是这么做的，把推理形式化为 MDP），但**regret 界不会跟着搬过来**，因为 minimax 结构不存在。
- **一个可测的后果**：UCT 的关键是"探索 vs 利用"的平衡由 `√(log n / n)` 保证；当价值函数有偏时，**这个平衡点会系统性地偏向错误方向**（`2606.28661` 的"selection ceiling"就是这个现象的定量版）。

### 3.3 真正能迁移的结果一：覆盖 vs 选择的分离（`2606.28661`）

这是本报告找到的**唯一一套既带公式、又能直接解释 LLM 实测的框架**：

| 量 | 公式 | 含义 |
|---|---|---|
| 设计效应 | `d_eff = 1 + (n-1)ρ` | 样本相关 ρ 会使计数方差膨胀 |
| 有效样本数 | `n_eff = n / [1 + (n-1)ρ]` | 可用的"独立"抽样数 |
| **相关天花板** | **`n_eff → 1/ρ`** | **采样再多也只有 1/ρ 个有效独立样本** |
| 第 n 个样本的边际价值 | `(1-ρ) / [1+(n-1)ρ]^2` | 衰减 ∝ `1/(ρn)²` |
| 覆盖税 | `pass@n ≤ 1 - (1-s)^n` | 相关性把覆盖率压到独立曲线之下 |
| 覆盖尾部 | `P[K=0] ~ n^{-α}` | 异质性导致**幂律**而非指数尾 |
| **选择天花板** | **`π_mode = P_q[a*_q 正确]`** | **自一致性打不过众数命中率** |
| 多数投票界 | `P[θ > 1/2] ≈ Φ((s-1/2)/√(ρs(1-s)))` | 松散下界 |

**实测（GSM8K, Llama-3-8B-Instruct, 每题 10⁴ 样本）**：**覆盖升到 1.00，自一致性停在 0.87**。→ 这两个数之间的差就是"**覆盖-选择缺口**"。

**为什么这是 AC2 想要的**：它给出了**在随机、相关、非凸条件下仍然成立的界**（覆盖的并集界 + 相关性的有效样本天花板），而且**条件是显式的**（ρ、s、独立性假设）。

### 3.4 真正能迁移的结果二：compute-optimal 分配（`2408.03314`）

- **定理形状的结论**：给定 FLOPs 预算，**最优的 test-time 策略依赖题目难度**——易题用**串行修订**（长 CoT），难题用**并行搜索 + 验证器**（best-of-N）。
- **效应量**：这个"难度感知"的策略比**固定 best-of-N** 高效 **>4×**。
- **它保证的是什么**：不是"找到最优答案"，而是"**在给定预算下最大化正确率的分配方式**"——即**policy optimality**，不是 search optimality。
- **为什么它比 SA/MCTS 更适合**：它的假设只有"存在一个难度可分的题目分布 + 一个验证器"，**不需要**可采纳启发式、不需要对手、不需要可评估的中间目标。

### 3.5 最接近"定理"的一篇：beam search 的可证 test-time scaling（`2609.38672`）

本篇是检索中**唯一同时满足"直指 beam search""有定理编号""有下界与上界"**的工作。它的形状值得单独说清，因为它标定了"在这个问题上能证到什么"：

| 结果 | 内容 |
|---|---|
| **Thm 1（vanilla beam 的样本下界）** | 要让**最优响应存活**，至少需要 **Ω(C\*(x)²)** 个样本，`C\*(x)` = prompt x 的 **token 级覆盖系数** |
| **Thm 2 / Cor 1（CF-Beam 的上界）** | 置信度过滤（threshold 落在均值下方相对 1/L）把对覆盖的依赖从 **平方降到接近线性**：**Õ(C\*_max)**（固定 horizon、prefix gap、目标精度） |
| **Thm 3（regret 下界）** | 即使 CF-Beam，也存在硬实例使 regret 为 **Ω(√(C̄(x)·ε_RM²(x)))**——**奖励模型误差 ε_RM 直接进 regret**，无法被搜索消掉 |
| 与其他 test-time 方法的对照 | 已有 2025 年的 regret 界形如 `O(C̄·log(1/ε_RM)/Ñ + √(Ñ·ε_RM²))`；本文指出其对 `C̄` 的依赖**随深度 L 指数增长** |

**三条可直接引用的推论**：
1. **"宽度"不是免费的**：`C\*` 随序列长度增长 ⇒ **固定宽度下，最优响应存活的概率随深度平方级恶化**。这**从定理侧**解释了 §2 的 beam curse（BLEU 在 beam 4–8 见顶），也解释了为什么 `1908.10090` 里 **Beam-100 只把搜索错误率从 57.7% 降到 53.62%**。
2. **reward model 误差不能被搜索吸收**：`ε_RM` 出现在 regret **下界**里 ⇒ **搜索再优也压不掉验证器误差**。这与 T-PR-11 的"验证质量 ρ 是 compute↔capability 汇率"是同一件事的两种写法（一个是汇率，一个是 regret 项）。
3. **定理的正确量词是"样本量"而非"最优性"** ⇒ 本报告的 §2 判决（"没有对全局最优的保证"）**成立且被加强**：不是没人证，而是**能证的只有样本复杂度**。

### 3.6 核心问：test-time compute 到底在哪个空间搜索？

任务书点名要区分 **latent（连续高维）** 与 **token sequence（离散组合）**。两者性质确实**完全不同**，而且这个差别是可操作的：

| 维度 | token 序列空间 | latent（连续）空间 |
|---|---|---|
| **结构** | 离散、组合爆炸（\|V\|^d） | 连续、有度量（可定义邻域/梯度） |
| **可用的优化工具** | 只能**采样 + 剪枝 + 投票**（无梯度） | **可以做梯度上升**：`2505.13308`（LatentSeek）把目标写成 `z* = argmax_z E_{x~π(x\|z,c)}[R(x,c)]`，用 REINFORCE `z ← z + η∇_z J(z)` 直接优化 latent |
| **收敛证据** | 覆盖天花板 `n_eff → 1/ρ`；越采越像 | LatentSeek 报告**平均难度题目 < 2 次迭代收敛**；`2601.17275`（DLR）在 latent 采 K 条轨迹后只喂 1 条给冻结主模型解码，**18% 的前向成本**下 GSM8K **55.4** vs token 级 GRPO **46.2** |
| **已知的代价** | 序列长度爆炸（长度 = 算力） | **算术/精确符号任务反而更差**（见下） |
| **有效性证据的边界** | CoT 在规划/算术上强 | latent 在**规划/探索**上强、在**精确算术**上弱 |

**关键的对照数据**：Coconut（Meta, 2024）在图规划基准 ProsQA 上 **97.0% vs CoT 77.5%**（14.2 个 latent 步 vs 49.4 tokens），但在 **GSM8K 上 34% vs CoT 43%**（二手转述，未见原文表；标 [待核验] conf 0.6）。→ **"latent 更擅长探索、token 更擅长精确"** 这个分工与本报告的抽象（§5）一致：**latent 搜索解决的问题是"找到候选"，token 搜索解决的问题是"把候选写死以便验证"**。

**为什么这个区分对本题是决定性的**：如果搜索在 latent 空间，那么 **SA/梯度类工具的假设（邻域、连续性、可微代理）至少部分成立**，`2609.38672` 的覆盖系数 `C\*` 也不再是"采样要多少次"的问题；如果搜索在 token 空间（当前所有 CoT 系统），那么**只能得到覆盖/选择型的界**。→ **"LLM 推理能否套用经典搜索保证"这个问题没有单一答案，答案取决于在哪个空间搜**——这本身就是一个应当写进结论的区分。

## 5. Q4：如果直接搬不通，正确的抽象是什么（AC4）

### 5.1 四个候选按三条判据打分

判据来自任务书：能否解释 **G2**（best-of-n ≥ 回溯）、**G3**（scratchpad 可压缩）、并**预测 S8B**（掩码条件重建）。

| 候选抽象 | 解释 G2 | 解释 G3 | 预测 S8B | 得分 |
|---|---|---|---|---|
| **(a) 近似贝叶斯推断**（训练把搜索烧进权重） | ✅ 采样是从已训练好的近似后验里抽，比"推理时搜"便宜 | ⚠️ 弱：不解释"草稿内容可同义改写而不掉分" | ❌ 不预测 | **1.5 / 3** |
| **(b) CoT = 外部工作内存 + 受限前缀搜索** | ✅✅ 回溯贵是因为每步要**重算长前缀**；best-of-n 是**并行前缀采样**，无回溯开销 | ✅ 草稿是**状态**不是**计算**，所以可压缩/可改写（与 G3 完全一致；也与 G4 的"记忆预算"解释一致） | ✅ 预测：掩码重建**换的是前缀选择的目标**，不改搜索深度 | **3 / 3** |
| **(c) compute-optimal inference** | ✅ 用"难度匹配"解释：易题回溯、难题并行 | ❌ 不解释 | ⚠️ 弱（只能说预算相同） | **1.5 / 3** |
| **(d) 信息论（提升 prompt↔answer 互信息）** | ❌ 不解释 | ❌ 不解释 | ❌ 不预测 | **0 / 3** |

### 5.2 判决

> **推荐 (b) 为主、(c) 为预算层，并加一条第一性修正：搜索不是瓶颈，目标对齐才是。**
> **理由一（解释力）**：(b) 是唯一三条全中的抽象。它把 "CoT" 从"搜索算法"降级为"**外部内存**"，把"搜索"限定在**前缀选择**这一个稀疏决策点上——这正好解释了为什么 **token 空间的搜索是免费的（自回归必然做）而前缀分支需要外部干预**（采样多条/树搜索）。
> **理由二（为什么不能只靠 (b)）**：`1908.10090` 证明**在错的目标上做更优的搜索会更糟**（BLEU 30.3→2.1）。所以任何抽象若不同时说明"**目标函数是否对齐效用**"，都会重演这个失败。(b) 说明了"搜哪儿"，`2606.28661` 的 `π_mode` 天花板说明了"搜到了也未必选得对"。
> **理由三（可反驳的预测）**：若 (b) 成立，则在**固定 token 预算**下比较三种花法——(i) 单链加长、(ii) n 条独立链 + 投票、(iii) 宽度 w 的 beam——应当看到：**(ii) 单调上升但饱和于 `1/ρ` 相关天花板；(iii) 非单调**（对应 beam search curse，因为剪枝丢掉的候选回不来）；**(i) 受任务内在 token 下界限制**（`2602.02909`）。**三条预测都可测，且互不相同**——这是 (b) 优于 (a)(c)(d) 的判据。

### 5.3 它解释/预测了哪些已知现象

| 现象 | (b) 的解释 |
|---|---|
| **G2：best-of-n ≥ 回溯**（`2504.07052`） | 回溯要**重算前缀**（长链的每一步都要重新前向），best-of-n 是**并行**且**互不依赖**；在固定算力下后者的有效独立样本更多（受 `1/ρ` 限制但通常仍 > 1） |
| **G3：scratchpad 可同义改写而不掉分**（Anthropic 2025） | 草稿是**外部状态**，只要语义等价，下游计算不变 → 可压缩是 (b) 的直接推论；若草稿是"隐藏计算"，改写字面就会掉分 |
| **G4：CoT vs 循环 transformer 的记忆预算**（`2605.30757`） | (b) 把"内存"与"计算"分开：CoT 扩的是**内存**（context 可增长），循环层扩的是**深度**（状态固定） |
| **G1：空草稿（只有 `....`）提升大幅缩水** | 空草稿只买了 token 预算，**没买状态**；(b) 预测"无内容 ⇒ 无新状态 ⇒ 收益趋零"，与观测一致 |
| **S8B（掩码条件重建）**（T-PR-13 §5.1 待测） | (b) 预测：它改变的是**前缀选择的目标（选哪个条件去重建）**，不改搜索深度 ⇒ 若 S8B 有效，收益应出现在"**选中正确前缀**"的指标上（如 O6），而**不应**出现在"每步准确率"上 |

## 6. 反方质询（AC6，4 条）

### 质询 1：「`D17-1227` 已经给了最优性定理，你说"没有最优性定理"是错的」

**攻击**：Theorem 1 白纸黑字写了 optimality，你把它归到"没有保证"，是选择性引用。

**防御（部分接受，但反转其含义）**：我把它**完整列入**（§4 #3，并抄了定理与证书条件）。但请注意它的限定词是 **"modulo beam size"**——**保证的是"在你已经保留的候选集合内最优"**。而被剪掉的候选**永不返回**，所以这条定理对"是否找到全局最优"**零信息**。它真正保证的是**"可以停止"**（`B_1 ≤ best_{≤i}` 时后面不可能更好）。→ **它是终止定理，不是最优性定理。** 而且它自己指出：**加了 length normalization 就失效**（A2）。**所以我的表述应为"没有对全局最优的保证"，而不是"没有定理"。** 这一处我接受修正。

### 质询 2：「Hajek 定理存在，所以"非凸 landscape 下没有保证"是伪命题」

**攻击**：你前面说非凸条件下没有理论保证，后面又列了 Hajek 的充要条件，自相矛盾。

**防御（不接受，因为区分是实质的）**：我的原话是"**保证不可操作**"，不是"不存在"。三条具体理由：① `c ≥ d*` 里的 `d*` **要预先知道最深的非全局局部极小**——这是要求解问题本身；② 收敛是 `t→∞` 的 in probability，对数冷却需要**指数级迭代**；③ `2208.11444` 证明**即便用 Hajek 的最优调度，期望上仍远离全局最优**。→ **"定理存在"与"定理可用"是两件事**，这个区分正是本报告 §3.1 的全部内容。**但接受一点**：如果目标是"证明 SA 在原理上不被非凸性困住"，Hajek 确实做到了——我在 §3.1 已如实写出"定理真"。

### 质询 3：「你用 G2 支持 (b)，但 G2 同样能支持 (a)（采样便宜是因为已 amortize）」

**攻击**：一条证据支持两个候选，你怎么选？

**防御（接受前提，改用覆盖度判据）**：接受 G2 是**弱区分证据**。所以我没有用单条证据选抽象，而是用**三条判据的覆盖度**（§5.1）：(b) 3/3，(a) 1.5/3。**关键区分点是 G3**——(a) 完全不解释"为什么草稿可被同义改写而不掉分"，而 (b) 一句话就解释（草稿是状态不是计算）。→ 选抽象的规则是**"能解释最多条已知现象 + 给出最多条可否证预测"**，不是"被最多条证据支持"。后者本来就无法区分等价假设。

### 质询 4（自查）：「你的'表示墙'（T-PR-13）与这一轮的'搜索墙'是同一个东西吗？」

**攻击**：如果两个墙是同一个，你就是在概念堆叠；如果不是，你怎么保证它们不冲突？

**防御（自查结论：不是，且必须分开）**：
- **表示墙** = "这个能力**能不能**被离散语言承载"（`2410.21333`：CoT 在隐式统计学习上 −36.3，因为语言化把模式压成规则）。
- **搜索墙** = "承载之后，**在预算内能不能找到**"（`1908.10090`：精确搜索找到了，但找到的是空串）。
- **独立性的证据**：`1908.10090` 的失败**与语言承载无关**（翻译任务的输入输出都是语言），纯粹是**目标函数错位**。⇒ 两个墙**可分离**。
- **但本题暴露了第三件事**，比两个墙都更根本：**"找到最优"与"最优是好的"是两回事**。`1908.10090` 是这句话的定量证明（BLEU 30.3 → 2.1）。→ 我在 §5.2 把它写成"第一性修正"，而不是再造一个墙——因为**它不是"墙"（限制），是"方向错了"**。

### 8.1 最小可执行实验设计（供 Lead 本地跑）

**目标**：用**同一 token 预算**区分三种"花法"，检验 §5.2 的三条预测。

| 项 | 设计 |
|---|---|
| **固定** | 总 token 预算 B（如 4096）、模型、prompt、评测集（GSM8K 子集 + MATH 子集）、温度、n=3 重复 |
| **臂 1：单链加长** | 一条 CoT 用到 B 个 token |
| **臂 2：并行采样 + 投票** | n = B/L 条独立链（L = 单链步长），plurality vote |
| **臂 3：beam** | 宽度 w、总预算 B 的 beam search（同一打分器） |
| **扫描** | B ∈ {1k, 2k, 4k, 8k, 16k}，每臂每点同一预算 |
| **主指标** | 准确率 vs B 的曲线**形状**（单调/饱和/非单调） |
| **预测（可否证）** | ① 臂 2 **单调上升后饱和**（饱和点应由 `1/ρ` 预测；ρ 用同题多次采样的答案一致率估）② 臂 3 **非单调**（beam curse）③ 臂 1 受**任务内在 token 下界**限制（`2602.02909`） |
| **判据** | 若"臂 2 饱和 + 臂 3 非单调"同时出现 ⇒ (b) 成立；若臂 3 也单调 ⇒ (b) 的"剪枝丢信息"机制被否证 |
| **成本** | 纯推理，无训练；一个下午可跑完 B 扫描 |
| **附加（可选）** | 同时记录 `π_mode`（众数命中率）与覆盖率，验证 `2606.28661` 的缺口在本地上是否也出现 |

## 9. Q5（追加）：动态适配能力——能不能培养"按任务选策略"？（成璐 2026-11-08 转向）

> 前提变化：从"通用最优是否可能"转为"**场景适配**"。这一转向实际上**与本报告前八节的结论一致**——前八节证的是"通用最优不存在"，而不是"适配不可能"。本节回答四个子问题。

### 9.1 Q5.1 路由信号：什么任务特征决定广搜 vs 深搜？

| 候选信号 | 文献是否识别 | 有无定理/形式化 | 判决 |
|---|---|---|---|
| **错误代价不对称**（假阳性 vs 假阴性的代价） | 经典选择性预测 | ✅ **有，且是唯一有定理的**：给定 `c_fp, c_fn`，最小风险拒答/延后阈值为 `p* = c_fp/(c_fp+c_fn)`（Chow 规则的直接推论：风险 = `c_fp·FP + c_fn·FN`，对 `p` 线性 ⇒ 阈值由代价比唯一确定） | **采纳为首要信号**：它决定"该不该想"，不只是"想多深" |
| **任务是否可分解** | ✅ 本地 `long-insight-decomposability-survey.md`；`2402.03620`（structure composition） | 部分：可分解 ⇒ 深度可分摊（与 T-PR-07 的 pebbling/电路深度结果同构） | 采纳；但**可分解性是模型判出来的，不是题面给的** ⇒ 判错就全错 |
| **答案空间大小 / 是否有唯一解** | ✅ `2412.21187`（琐碎题过度思考 1,953% token）、`2026.findings-acl.1285`（O3 在 low/medium/high 三档都 97%，token +8% ⇒ **无自适应计算**） | ❌ 无形式化；只有经验曲线 | 采纳为**弱信号**；它更擅长识别"不需要想"，不擅长识别"必须要多想" |
| **模型自身能力**（同一题对不同模型难度不同） | ✅ **`2505.13379` Thinkless**：明确把"task complexity + model capability"共同作为路由输入；并给出**负结果**——**AIME 上路由器识别不出难度**（该数据集上推理模型也只有 28%） | 部分（DeGRPO 把模式选择与答案正确性解耦） | **必须加**：只按题目难度路由的**外置路由器会系统性失败在"最难但最该多想"的样本上** |

**Q5.1 判决**：**路由信号不是"哪个信号更好"，而是"信号必须成对"**——**(错误代价不对称, 模型自评能力)** 这一对是唯一能同时覆盖"该不该想"与"想多深"的组合，且其中一半（代价比）有定理。**只按难度路由 = Thinkless 的 AIME 失败模式**（conf 0.7）。

### 9.2 Q5.2 切换成本：有没有被量化过？

| 成本类型 | 是否被量化 | 数字（口径） |
|---|---|---|
| **总成本差**（低 effort vs 高 effort） | ✅ | Gemini 2.5 Flash：thinking 关 **\$0.60/M** vs 全开 **\$3.50/M**（≈**5.8×**，官方定价口径，二手转述）；Claude effort `low..max` 四档（产品接口，非论文） |

| **去掉冗余后的净收益** | ✅ | NoWait（EMNLP 2025）：压掉 "wait/hmm" 类反思词，长度降 **27%–51%**，五族模型**无明显掉分**（二手转述，ID 未核）；SelfBudgeter：MATH 上长度降 **74%**、平均压缩 **61%**，精度相当（二手，ID 未核） |

**Q5.2 判决**：**"该不该多想"的成本被量化得很清楚，"换过去"的成本几乎空白（N7）**。这有直接后果：**任何"先分类再切换"的架构，都缺一项关键预算参数**——切换本身的 token/准确率代价。→ 见 §9.5 的最小实验。

### 9.3 Q5.3 可激发性：prompt 够了，还是必须微调？撞哪面墙？

把文献按"**结构选择**"与"**调度决策**"两层拆开，结论非常干净：

| 层 | 能否纯 prompt 激发？ | 证据 |
|---|---|---|
| **结构选择**（选哪些推理模块、怎么组合） | ✅ **可以** | `2402.03620` Self-Discover：三个 meta-prompt（SELECT / ADAPT / IMPLEMENT），**无标签、无训练**，GPT-4/PaLM2 上最高 **+30%**；`2507.11423`：四种人类策略的 prompt 依从率 **32%–99%**（模型/策略差异大），且**无单一策略恒优**、oracle 选择器显示**大量 headroom** |
| **调度决策**（何时想、想多深、要不要切） | ❌ **prompt 不够，需训练/RL** | `2505.13379` Thinkless（DeGRPO，`<short>`/`<think>` 双控制 token）；`2506.18237` AdapThink（偏好调制）；SelfBudgeter（两阶段：先预测预算再 RL）；`2026.findings-acl.1285` 直接断言 **"models lack adaptive computation: they cannot modulate reasoning depth based on problem difficulty"** |
| **机制是否已在**（不需要新能力） | ✅ **已在** | **`2510.07364`**：base 模型 + steering 向量（在正确类别时点注入），**零权重更新、只 steer 12% 的 token**，恢复 base→thinking 差距的 **91%**（MATH500, Qwen2.5-32B + QwQ-32B）；结论是"thinking 模型主要学的是 **when** to deploy existing mechanisms" |

**→ 撞的是哪面墙？我的判决：不是 T-PR-13 的任何一面，而是第四面——"调度墙"。**

| 墙 | 定义 | Q5.3 是否撞 |
|---|---|---|
| 容量墙 | 参数不够装 | ❌ 不撞（`2510.07364` 零权重更新即恢复 91%） |
| 跨度墙 | 窗口/步数不够 | ❌ 不撞（不是长度问题，是"何时开始"的问题） |
| 表示墙 | 离散语言承载不了某类计算 | ❌ 不撞（推理机制本身可被激活；不像 `2410.21333` 的隐式统计学习） |
| **调度墙（本报告提出）** | **机制已在，但在正确的时点调用它的策略不在**（既非容量也非表示） | ✅ **撞这面** |

**为什么它值得单列**：前三面墙的失败模式是"**想了也做不到**"，调度墙的失败模式是"**能做到但没在该做的时候做**"。两者的补救手段完全不同：前三面靠**更多参数/更长窗口/更好表示**，调度墙靠**路由策略 + 校准**（也就是 Q5.1 的那一对信号）。**这解释了为什么"给模型更长预算"经常无效（`2026.findings-acl.1285`：O3 三档 effort 全 97%，token 只多 8%）——预算不是墙，调度才是。**
⚠️ **限定**：「调度墙」是**本报告的综合概念**，非文献既有术语；support 来自 `2510.07364` 的 91%/12% 与 Thinkless 的 AIME 负结果两处独立证据，**conf 0.55**。对外使用须注明来源是本报告（与 T-PR-13 三墙同样处理）。

### 9.4 Q5.4 三个动作的映射：整理 / 写SOP / 研究推进

任务书给了三个候选映射（整理=剪枝？写SOP=缓存路径？研究推进=迭代深化？）。逐条判定：

| 动作 | 对应搜索概念 | 判定 | 证据 / 经典风险 |
|---|---|---|---|
| **整理** | **剪枝 + 记忆压缩**（不只是剪枝） | **部分成立，须加"压缩"这一半** | 纯剪枝发生在**生成时**（token 层，丢掉不走的候选）；整理发生在**已生成内容**上（把走过的路径压短）。**压过头的代价有实测**：ACE `2510.04618` 记录 Dynamic Cheatsheet 一次整写后 context 从 **18,282 → 122 tokens**，准确率 **66.7% → 57.1%**；这正是搜索里"**把还要用的 open list 剪掉了**"。→ **正确做法是 delta 更新而非整写**（ACE 的 incremental delta），对应搜索里的"**保留 frontier，只压已关闭节点**" |
| **写SOP** | **缓存已探索路径** = macro-operator + **transposition table**（把一段成功路径固化成可复用动作） | **成立，且文献已成体系** | `2409.07429` AWM（从轨迹归纳 workflow 再选择性注入）；`2504.07952` Dynamic Cheatsheet（自适应记忆）；`2510.04618` ACE（Generator/Reflector/Curator + delta 更新）；Agentic Plan Caching（缓存 plan 模板）。**经典风险 = utility problem**（Minton 1990：学到的 macro 若检索/索引不好，会让搜索变慢）→ **可证伪预测：SOP 库增长应出现"收益见顶后下降"，除非检索是选择性的**（AWM 的"selectively inject"正是为此） |
| **研究推进** | **迭代深化（IDA\*）+ 放宽 bound**，不是"继续搜更久" | **成立，但前提被低估** | IDA\* 的定义特征是**每轮用一个更好的 bound 重来**；对应到 LLM，每轮的"更好 bound"必须是**更好的 verifier/更强的中间结论**，否则只是重复采样 → 撞 `2606.28661` 的 **selection ceiling `π_mode`**。`2408.03314` 的 sequential revision（易题）正是"带更好反馈的重来"，而 pure best-of-N 不是 |

**Q5.4 判决**：三个映射**方向都对，但每个都缺一个必要条件**——整理缺"**保留 frontier**"，SOP 缺"**选择性检索**"（否则 utility problem），研究推进缺"**每轮 bound 必须变好**"。**这三个必要条件恰好都是同一件事的三副面孔：整理/缓存/重启的价值全部取决于"你能不能判断哪条路值得留"——即 T-PR-11 的验证质量 ρ。**

### 9.5 Q5 的判决 + 最小可执行实验

**判决（conf 0.65）**：**meta-level 动态适配是可培养的，而且它不是"学一个新的搜索算法"，是"学一个调度策略"**。理由三条：
1. **机制已在**（`2510.07364` 91% / 12% token）⇒ 不需要新增能力，只需要新增**调用时点**。
2. **结构选择可纯 prompt 完成**（`2402.03620` +30%，`2507.11423` 依从率 32–99%）⇒ 一半的适配已经在 prompt 层可做。
3. **调度决策必须训练**（Thinkless / AdapThink / SelfBudgeter 全部要 RL 或两阶段），且**外置路由器在难样本上会失败**（Thinkless 的 AIME 负结果）⇒ **不要做"先分类再分派"的架构，要做"模型内部自己判"的架构**。

**最小可执行实验（Q5 版，纯推理 + 一个轻量微调可选）**

| 项 | 设计 |
|---|---|
| **目标** | 分离"**信号是否存在**"与"**策略是否可学**"两件事 |
| **臂 A：外置路由器** | 用题目特征（长度/是否多问/是否数值/模型自评难度）训练一个二分类器，决定 short / long；在 GSM8K+MATH+AIME 子集上跑 |
| **臂 B：prompt 内自判** | 同模型，加一句"先判断该题需要多少推理再作答"，不训练 |
| **臂 C：控制 token（轻量）** | 加 `<short>/<think>` 两 token，只训这两个 token 的 embedding（Thinkless 的最小版），其余冻结 |
| **主指标** | ① **路由准确率**（判"该多想"是否判对，用"long 才做对 / short 也做对"作标签）② **同预算准确率** ③ **切换成本**：分别测"全程 short""全程 long""按需切"三种的 token 与准确率 |
| **核心预测（可否证）** | 臂 A 在 AIME 类难题上**路由准确率显著低于** GSM8K（复现 Thinkless 的失败模式）；臂 C 明显优于臂 A（内部信号 > 外部特征）；**"按需切"若不能同时超过"全程 short"与"全程 long"的帕累托前沿，则说明切换成本 > 收益**（这正是 N7 的空白） |
| **成本** | 臂 A/B 纯推理；臂 C 只训 2 个 token 的 embedding，单卡小时级 |

## 10. 给 Lead 的五条结论

1. **"推理即搜索"这条路在数学上是可以走的，但走通的那一段不在搜索算法里，在目标函数里。** `1908.10090` 是决定性的：**精确搜索把 BLEU 从 30.3 打到 2.1**，因为模型给空串的分数最高。→ **凡是"换更强的搜索算法"的方案，都必须先回答"搜索的目标是否等于效用"**；否则更强的搜索只会更忠实地找到更糟的答案。这条对 pfb 是直接支持的（T-PR-11 已证：**验证质量 ρ 是 compute↔capability 的汇率**）。
2. **对外最硬的一条定理是这个**：vanilla beam search 要让最优响应存活，样本量至少 **Ω(C\*(x)²)**（`2609.38672` Thm 1），C\* 是 token 级覆盖系数；即使换成 CF-Beam，regret 下界里仍带 **ε_RM**（验证器误差）。→ **"加宽 beam 逼近最优"在定理层面就不成立，而"换更好的验证器"是唯一能压 regret 的手段。** 这条与 T-PR-11 的结论互为独立验证，可以并排引用。
3. **可以立刻引用的两个数字**：**`n_eff → 1/ρ`（采样天花板）** 与 **`π_mode`（自一致性天花板）**，以及它们在 GSM8K 上的实测差距（**覆盖 1.00 vs 自一致性 0.87**）。这两个量把"多采样总能变好"这个默认假设直接否掉了，而且是**公式 + 实测**双支撑——比任何"经验上会饱和"的说法都硬。
4. **Q5 的对外表述**：**"通用最优是幻想"是对的，但"适配"不等于"选算法"**——适配的真身是 **"何时开始想、想多深、何时停"** 的调度，而它的失败面是**第四面墙（调度墙）**：机制都在（`2510.07364` 零权重更新恢复 91% 差距），缺的是在正确时点调用它的策略。**对外最有说服力的一句**：**"给模型更长预算经常无效，因为预算不是墙，调度才是"**（`2026.findings-acl.1285`：O3 三档 effort 全 97%，token 只多 8%）。
5. **对外材料的正确表述**：不要说"LLM 推理不是搜索"（它在前缀层面**是**），要说"**LLM 推理是受限前缀搜索 + 外部工作内存，其瓶颈是目标对齐与选择，而非搜索深度**"。这句话同时解释了 G2/G3/G4、预测了 S8B，并给出一条可否证的实验（§8.1）。
