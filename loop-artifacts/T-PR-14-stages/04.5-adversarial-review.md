# 04.5 · 反方复核（T-PR-14，4 条）

1. **「`D17-1227` 明明给了 optimality 定理，你说'没有最优性定理'是选择性引用」**
   → **部分接受**：定理已完整列入 §4 #3，并抄了 Theorem 1/3 与终止证书条件。但限定词是 **"modulo beam size"**——保证的是"**已保留候选集内最优**"，被剪掉的**永不返回** ⇒ 对"是否找到全局最优"零信息。它真正保证的是**可以停**（`B_1 ≤ best_{≤i}`）。**故收敛为"没有对全局最优的保证"，而非"没有定理"**（对应 C-01）。

2. **「Hajek 定理存在 ⇒ 你说'非凸下没保证'是伪命题」**
   → **不接受，但区分是实质的**：原话是"**保证不可操作**"。三条：① `d*` 要预先知道最深的非全局局部极小（= 要求解问题本身）；② 收敛是 `t→∞` in probability，对数冷却需指数级迭代；③ `2208.11444` 证明**即便用 Hajek 的最优调度，期望上仍远离全局最优**。**"定理存在"≠"定理可用"。** 已在 §3.1 如实写出"定理真"。

3. **「G2 支持 (b)，但也支持 (a)（采样便宜因已 amortize）」**
   → **接受前提，换判据**：G2 是**弱区分证据**，故不用单条证据选抽象，而用**三判据覆盖度**（3/3 vs 1.5/3）。关键区分点是 **G3**——(a) 完全不解释"草稿可同义改写而不掉分"，(b) 一句解释（草稿是**状态**不是**计算**）。规则：**能解释最多现象 + 给出最多可否证预测**，而非"被最多证据支持"（后者无法区分等价假设）。

4. **（自查）「你的'表示墙'与'搜索墙'是同一个东西吗？」**
   → **自查结论：不是，必须分开**。表示墙=能否被离散语言承载（`2410.21333` 隐式统计学习 −36.3）；搜索墙=承载后在预算内能否找到（`1908.10090` 找到了但找到的是空串）。**独立性证据**：`1908.10090` 的失败与语言承载无关（翻译任务输入输出都是语言），纯属目标错位 ⇒ 两墙可分离。**另**：本题暴露的第三件事（"找到最优"≠"最优是好的"）**不是墙而是方向错误**，故写成"第一性修正"而未再造概念。
