## 2. 关键路径与回退点

- **关键路径**：A2 → A4 → A11。A4 是本轮唯一**推翻已有结论**的动作（第一轮答案是错的），因此设了强制回退点：**若 A4 的结论改变，必须重写 §3 并同步 §0/§4/§8/§10**（实际执行了 R1–R3 三条修订）。
- **回退点二**：A7。只要发现编号不符，必须回退到"未实访不引用"的硬规则，而不是"先写上、以后再说"。
