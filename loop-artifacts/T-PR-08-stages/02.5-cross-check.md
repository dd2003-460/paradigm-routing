> 任务书未指定必须对照的本地文献，故对照对象取最近的三篇（T-PR-07 与本仓库已有 survey）。

## 1. 与 T-PR-07（`research/long-insight-decomposability-survey.md`）

| T-PR-07 结论 | 与本任务的接口 | 判定 |
|---|---|---|
| 瓶颈在 verifier/选择器（`2407.13692`、`2407.21787`） | **同一瓶颈**：MoA 的 aggregator 就是 verifier；`2603.20324` 的选择瓶颈与 SCORE 的 verifier 瓶颈是同一变量 | **强一致**，两任务独立收敛 |
| 覆盖率 >95% 而选择器 plateau | 直接支持 Q5 的"预算混杂"判断：多 agent 的增益很可能也是"多采样" | 复用 |
| 存在任务内在 token 下界（`2602.02909`） | 为本任务 L1 提供一个跨任务的下界视角：MoA 的层数是不是也有下界？**无人做过** | 新问题 |

**净结论**：两个任务不是并列关系，而是**同一现象的两个入口**——T-PR-07 从"单模型的推理链"进，本任务从"多模型的组合结构"进，出口都是"选择器/聚合器"。

## 2. 与 `research/cot-necessity-survey.md` §G

- G2（`2504.07052` 回溯 vs best-of-n）与本任务 Q5 **同构**：都在问"顺序组合 vs 并行采样"哪个划算。G2 的答案是"回溯不总划算"，与本报告 §6 的"分层 > 加宽（`2505.24205` §6）"并列时要注意：**一个是搜索策略，一个是结构深度，不可混用**。
- G4（`2605.30757` CoT=可扩展工作内存）对 L1 有间接意义：MoA 的 aggregator 看到的上下文就是它的"工作内存"，因此 **MoA 的 L1 行为受 aggregator 窗口限制**——这条在文献里没有被形式化（→ 可立项）。

## 3. 与 `research/icl-generalization-survey.md`

- D2（`2602.03485`：反思多为确认性 recheck）**直接适用**于 MoA：aggregator 的"综合"很可能也是确认性而非纠错性。→ **这解释了 `2603.20324` 的"合成在 80% 情况下输给单模型"**。两者是同一机制的不同观察面。
- B1（`2510.02370` 置信度路由）：与 MoE 的 router 是同构问题（都是"按输入置信度选专家"）。**本报告未找到把两者对起来的论文**（→ 负结果之外的一个可做点）。
