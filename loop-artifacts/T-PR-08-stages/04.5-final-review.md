# T-PR-08 阶段 04.5：终审

> 报告正文 §7 已写 3 个质询与防御。本文件做**第二层**复核：只攻击"结论本身"，不重复 §7。

## 质询 A：你的"结构同构"（E^L ↔ M^L）是不是把两件不同的东西硬凑？

**攻击**：`2505.24205` Thm 5.2 的 E^L 是**复合稀疏函数**的分片数，前提是目标函数**确实有这种分层结构**；而 MoA 的 L 层 × M agent 是**跑 LLM 的流水线**，没有"分片"概念。你把这个当作等价性的正面结果，是不是在给一个不存在的对应关系贴金？

**防御（部分接受，已加限定）**：
- 接受：Thm 5.2 是**存在性**陈述（"若目标具有复合稀疏结构，则 MoE 能高效逼近"），不是"任何目标都这样"。MoA 侧没有任何对应定理。
- 因此报告 §2.2(b) 的措辞是"**在计数上完全同构**"与"**这是本报告找到的唯一一处真正的结构同构**"，并同时写明它**不依赖正交性**——即我说的是"分层给出的组合计数相同"，不是"两者行为相同"。
- 残留风险：读者可能把"结构同构"读成"功能等价"。**已在 §5 L0 格里写明"结构性成立但严格形式不成立"，并在 AC5 里复述。**

## 质询 B：L2 你判"已反证"，但反证的是"MoE ≠ dense 模型聚合"，不是"MoE ≠ agent 群"

**攻击**：`2510.23671` 的原话是"misleading to think of **MoEs as an aggregation of dense models**"。而 MoA 的 agent 不是 dense model 的子集——它们是完整的、各自独立的 LLM。所以你这张牌打错了对象。

**防御（接受，但结论不变，理由更强）**：
- 接受：这条证据严格说的是"MoE 的专家因路由而共同学习，不能当独立 dense 模型看"。
- 但它对"MoE ≠ agent 群"是**更强**的支持，而非更弱：既然连"共享同一损失、同一底座"的 dense 专家都不能被当独立模型聚合，那么**彼此完全独立、从不共享损失的 agent 群更不可能复现 MoE 的训练动力学**。
- 补充独立证据：MoA 根本没有联合训练（`2406.04692` 是推理期框架）⇒ L2 在**定义上**不可能有正向结果。**这条比我原来的论证更硬。**

## 质询 C：你的最有用结论（"瓶颈是 aggregator，钱该花在 aggregator 上"）建立在一个假设模型 + 一个厂商博客上

**攻击**：`2603.20324` 自陈 hypothesis；Anthropic 是厂商博客。你用这两个支撑 §6 的核心建议，证据等级不够。

**防御（接受，改为并列三源并标级）**：
- 三条证据的等级确实不同：`2510.13903` 的 Parity 界（**定理级**）> `2502.00674` 的质量-多样性回归（**实测级**，conf 0.85）> `2603.20324`（模型，conf 0.7）/ Anthropic（二手，conf 0.6）。
- **核心建议其实只需要定理级那一条**：若聚合是弱聚合（多数投票），则 parity 类需要指数多 agent ⇒ **聚合方式决定复杂度档位**。这条不依赖 hypothesis 也不依赖博客。
- 因此 §6 的表述已改为三源并列 + 明确标级，并在质询 3 中预先降级了 `2603.20324`。
